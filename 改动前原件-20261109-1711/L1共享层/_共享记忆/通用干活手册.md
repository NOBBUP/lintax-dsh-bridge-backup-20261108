## 〇、⛔ 第一条硬性规矩：不准重启工作台

> **宿主 2026-11-01 原话：「所有任务都不准重启！刷新页面就刷新，不能重启工作台」**
> 这条**优先级高于本文档其它一切内容**。

### 为什么

重启会让引擎把内存里**所有会话的 Agent 全部销毁**：

```
重启工作台
  → 引擎重启
  → 10 个场景会话的 agentAvailable 变 false
  → 11 个面板全部卡在「重新连接中…」
  → 宿主看到的就是"全都断了"
```

宿主已经因此投诉过**两次**。历史违规记录（`工具\查违规重启.mjs` 可复现）：

| 时间 | 谁 | 次 |
|---|---|---|
| 15:30 / 15:38 / 15:39 / 16:08 / 16:29 | 工作台改造 | **5 次** |
| 15:50 / 11:59 | 命令 | 2 次 |

### 明令禁止的动作

```
❌ node 工具\一键重启工作台.mjs
❌ node 工具\一键收尾-重启并迁D盘.cmd
❌ taskkill /IM electron.exe /F
❌ Stop-Process -Name electron -Force
❌ 杀掉占 3083 的进程
❌ 通过 start.vbs / 启动器 exe 拉起新实例
```

**这些脚本已被物理禁用**（执行会报错退出，码 403），但**直接 taskkill 仍能绕过** —— 所以靠自觉。

### ✅ 正确的"刷新"方式

**核心原则（宿主原话）：**
> 「想看工作台 UI 改造是否成功、是否有效，**不要重启工作台，而是对应的那个页面刷新**」

| 改了什么 | 怎么让它生效 | 会断连吗 |
|---|---|---|
| `外壳\renderer\renderers.js` | **点顶栏 ⟳**（热更新，重插 script） | ❌ 不会 |
| `外壳\renderer\styles.css` | 点顶栏 ⟳ | ❌ 不会 |
| `外壳\scenarios\*.json` | 点顶栏 ⟳（重载场景 DOM） | ⚠️ 重绘面板，但不重启进程 |
| **面板里的某个网页**（个人站/嵌入页） | **点那个面板自己的「🔄 刷新网页」按钮** | ❌ 不会 |
| `外壳\main.js` / `preload.js` | **必须重启才生效** → **只能由宿主决定，不许自己做** | — |

**刷新有三档（`reloadScene(mode)`）：**
- `'soft'`（默认）：只重灌 `renderers.js`，**不碰 DOM、不碰 webview** → AI 对话完全不断
- `'panel'`：重跑各面板 renderer 函数，**保留 webview 实例** → 只重建非 harness 面板
- `'full'`：清空重建场景（**会断连**）→ 只有场景 json 改了才用，且绝不作为默认

### 如果你改的是 main.js / preload.js

**停下，报告命令场景或宿主，不要自己重启。**

改完先做静态验证（`node --check`），然后等宿主手动重启。
宿主重启时会有短暂断连，那是**宿主主动**的行为，不是你的。

